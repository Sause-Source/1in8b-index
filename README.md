# 1in8b パラメータ指数拡張機能

1in8b.lifeの「人生地図」に記録された各年のパラメータから平均値を計算し、死亡後の画面に表示するChrome拡張機能です。

## 表示する指数

- 幸福度
- 健康度
- 人間関係
- 知識
- 純資産

各指数は小数第1位まで表示します。死亡年の記録は平均の計算から除外されます。表示には1in8b.life上に人生の記録があることが必要です。

## インストール方法

現在、この拡張機能はChromeウェブストアではなく、ソースフォルダーから読み込んでインストールします。

1. このリポジトリをダウンロードし、ZIPの場合は展開します。
2. Chromeで `chrome://extensions` を開きます。
3. 画面右上の「デベロッパー モード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を選択します。
5. `manifest.json` が入っているプロジェクトフォルダーを選択します。
6. `https://1in8b.life/` を開き、人生地図の死亡後の画面を表示します。

画面内に「各パラメータの平均指数」が表示されます。

## 動作範囲とプライバシー

- 対象サイトは `https://1in8b.life/` です。
- この拡張機能は1in8b.lifeのページ内にある人生の記録を読み取り、画面に平均値を追加します。
- 拡張機能から外部サービスへデータを送信する処理はありません。
- サイト側の画面構成やデータ形式が変更されると、正しく表示されなくなる場合があります。

## 表示されない場合

- Chromeの拡張機能ページで、この拡張機能が有効になっていることを確認してください。
- 対象ページが `https://1in8b.life/` であることを確認してください。
- 人生地図の死亡後の画面を開いてください。平均値はその画面でのみ表示されます。
- インストール後に拡張機能のファイルを変更した場合は、`chrome://extensions` で拡張機能の再読み込みを行い、対象ページも再読み込みしてください。

## 開発

この拡張機能はManifest V3を使用し、追加のパッケージインストールなしで動作します。主なファイルは次のとおりです。

- `manifest.json`: 拡張機能の設定と対象サイト
- `content.js`: 平均値の計算と画面への表示
- `style.css`: 表示部分のスタイル
